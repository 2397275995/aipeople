灵山胜景 AI 数字人导览系统 - 使用说明

一、项目简介

本项目是一个面向景区导览场景的 AI 数字人问答系统，主题为“灵山胜景 AI”。系统支持游客通过文字或语音向 AI 导游提问，AI 会结合景区资料进行回答，并通过前端数字人形象进行讲解展示。

项目主要能力包括：
1. 景区智能问答：围绕灵山胜景的历史、文化、景点特色、游览建议等内容进行自然语言问答。
2. 知识库检索增强：后端基于景区资料构建向量库，回答时参考官方资料，提高回答可靠性。
3. AI 数字人展示：前端提供数字人形象，支持说话状态、口型变化和讲解状态展示。
4. 语音输入与语音合成：支持语音识别和 TTS 讲解能力，便于游客自然交互。
5. 路线推荐：可根据游客需求推荐适合的游览路线。
6. 管理后台：项目包含管理后台入口，便于后续维护知识库和查看系统数据。

二、交付内容说明

本交付包建议包含以下内容：

1. ScenicGuideBackend.exe
   后端服务可执行文件，用于启动 FastAPI 后端接口服务。

2. web-client 或 web-client/dist
   前端页面工程或前端构建产物。

3. backend/.env
   后端配置文件，包含服务端口、模型配置、讯飞数字人配置、大模型 API 配置等。

4. README.txt
   当前使用说明文档。

5. 依赖说明.txt
   说明系统依赖、运行环境、主要第三方库与外部服务配置。

6. 运行方式.txt
   面向演示或验收的启动步骤。

7. 介绍稿子.txt
   用于答辩、演示或项目介绍的讲解稿。

三、推荐运行环境

操作系统：Windows 10 / Windows 11
Python：建议 Python 3.10 或 3.11
Node.js：建议 Node.js 18 或以上
浏览器：推荐 Microsoft Edge 或 Google Chrome
网络：首次加载模型、调用大模型、调用讯飞数字人服务时需要联网

四、基本启动方式

方式一：使用可执行文件启动后端

1. 进入后端可执行文件所在目录。
2. 双击 ScenicGuideBackend.exe，或在 PowerShell 中执行：

   .\ScenicGuideBackend.exe

3. 后端默认启动地址：

   http://localhost:8000

4. 健康检查地址：

   http://localhost:8000/health

5. API 文档地址：

   http://localhost:8000/docs

方式二：源码方式启动后端

1. 打开 PowerShell。
2. 进入后端目录：

   cd backend

3. 激活虚拟环境：

   .\.venv\Scripts\Activate.ps1

4. 设置 HuggingFace 镜像：

   $env:HF_ENDPOINT="https://hf-mirror.com"

5. 启动后端：

   python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload

方式三：启动前端

1. 打开新的 PowerShell 窗口。
2. 进入前端目录：

   cd web-client

3. 安装依赖：

   npm install

4. 启动前端：

   npm run dev

5. 浏览器打开：

   http://localhost:5173

五、使用流程

1. 启动后端服务。
2. 启动前端页面。
3. 打开浏览器访问 http://localhost:5173。
4. 在输入框中输入问题，例如：
   - 灵山大佛有什么历史？
   - 推荐一条适合第一次来的游客路线。
   - 梵宫有什么特色？
5. AI 会返回回答，并在对话开始后显示数字人形象。
6. 数字人会根据回答内容进入讲解状态。

六、注意事项

1. 如果前端提示后端离线，请确认后端服务已经启动，并访问 http://localhost:8000/health 检查。
2. 如果首次启动较慢，通常是因为正在加载或下载向量模型、语音模型。
3. 如果 HuggingFace 下载较慢，请设置 HF_ENDPOINT=https://hf-mirror.com。
4. 如果数字人语音没有声音，请先点击页面一次，再发送问题；浏览器可能会限制自动播放声音。
5. 如果调用讯飞数字人视频生成超时，可能是网络或服务接口耗时较长，可稍后重试。
6. .env 文件中包含 API Key 等敏感配置，正式提交公开仓库前应脱敏。

七、项目亮点

1. 将景区知识库、AI 问答和数字人导览结合，形成面向游客的智能导览体验。
2. 支持 RAG 检索增强，回答不是完全依赖大模型自由生成，而是结合景区资料。
3. 前端界面简洁现代，适合展厅、游客中心、自助导览屏等场景。
4. 后端采用 FastAPI 架构，接口清晰，便于扩展更多景区资料与业务模块。
5. 可继续对接在线数字人、语音合成、语音识别等能力，具备较好的扩展空间。
