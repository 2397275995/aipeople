## 四、非功能性需求清单

| 类别 | 指标项 | 要求 | 优先级 |
|------|--------|------|--------|
| **AI 能力** | 多模态大模型 | 至少接入 1 个多模态 LLM（开源或 API） | **P0** |
| **准确性** | 事实性问答准确率 | ≥ 90%（基于示范景区标准测试集） | **P0** |
| **准确性** | 知识库覆盖 | 必须基于官方示范景区资料包构建本地知识库 | **P0** |
| **自然度** | 口型同步 | 语音与口型基本同步，无明显延迟感 | **P0** |
| **自然度** | 语音合成 | 发音清晰、语调自然，无明显机械感 | **P0** |
| **自然度** | 表情配合 | 表情与回答情感基本匹配 | **P0** |
| **性能** | 语音问答端到端延迟 | 从松开麦克风到开始播放回答 **< 5 秒** | **P0** |
| **性能** | 文本问答延迟 | **< 3 秒**（首 token 或完整回答） | **P1** |
| **性能** | ASR 识别延迟 | 10 秒音频 **< 2 秒** 出结果 | **P1** |
| **并发** | 同时在线用户 | 支持 **≥ 50** 并发会话（初赛演示级） | **P1** |
| **并发** | 峰值扩展 | 架构支持水平扩展至 **200+** 并发 | **P2** |
| **稳定性** | 可用性 | 演示期间无崩溃、无长时间无响应（> 30s） | **P0** |
| **稳定性** | 异常恢复 | AI/语音服务超时自动降级（文字回答兜底） | **P1** |
| **安全** | 管理后台鉴权 | 管理员账号密码 + Token 鉴权 | **P0** |
| **安全** | 接口限流 | 防止恶意刷接口 | **P1** |
| **兼容** | 终端适配 | 支持 Chrome/Edge 现代浏览器 + 移动端 H5 | **P0** |
| **兼容** | 麦克风权限 | 优雅处理权限拒绝场景 | **P0** |
| **扩展** | GPS/弱定位场景 | 提出 GPS 不可用时的替代方案（手动选点/二维码） | **P2** |
| **文档** | 交付物 | 源码、部署手册、设计文档、PPT、≤7min 演示视频 | **P0** |

  │                      │<──text──────────│                │                 │                │              │

### 5.2 关键接口详细定义

#### ① ASR 语音识别

```http
POST /api/v1/asr/recognize
Content-Type: multipart/form-data

Request:
  - audio: File (wav/webm, ≤60s)
  - sessionId: string
  - lang: "zh" | "en" (default: "zh")

Response 200:
{
  "code": 0,
  "data": {
    "text": "这个景区有什么历史故事？",
    "confidence": 0.95,
    "durationMs": 3200
  }
}
```

#### ② 核心问答接口（文本/语音共用）

```http
POST /api/v1/chat/ask
Content-Type: application/json

Request:
{
  "sessionId": "sess_abc123",
  "text": "这个景区有什么历史故事？",
  "inputType": "voice" | "text",
  "preference": ["history", "culture"],
  "poiId": "poi_001"
}

Response 200:
{
  "code": 0,
  "data": {
    "messageId": "msg_xyz",
    "answerText": "本景区始建于唐代，距今已有1300多年历史……",
    "emotionTag": "friendly",
    "confidence": 0.92,
    "sources": [
      { "docId": "doc_01", "title": "景区历史简介", "snippet": "…" }
    ],
    "tts": {
      "audioUrl": "https://cdn.../tts/msg_xyz.mp3",
      "durationMs": 8500,
      "phonemes": [
        { "phone": "b", "startMs": 0, "endMs": 80 },
        { "phone": "en3", "startMs": 80, "endMs": 200 }
      ]
    },
    "avatar": {
      "expression": "smile",
      "gesture": "explain"
    }
  }
}
```

#### ③ 流式问答（P1 加分）

```http
WebSocket ws://host/api/v1/chat/stream

Client → Server:
{ "sessionId": "...", "text": "...", "inputType": "text" }

Server → Client (多次推送):
{ "type": "token", "content": "本景区" }
{ "type": "token", "content": "始建于" }
{ "type": "done", "emotionTag": "friendly", "sources": [...] }
{ "type": "tts", "audioUrl": "...", "phonemes": [...] }
```

### 6.2 技术选型建议

| 层级 | 推荐方案 | 说明 |
|------|----------|------|
| 前端（C端） | Vue3/React + Live2D/WebGL | H5 优先，兼顾景区终端 |
| 前端（B端） | Vue3 + Element Plus + ECharts | 管理后台 + 数据大屏 |
| 后端 | Python FastAPI / Java Spring Boot | Python 更适合 AI 集成 |
| ASR | Whisper / 讯飞/阿里 API | 开源或国产均可 |
| TTS | Edge-TTS / ParaTTS / CosyVoice | 需输出音素时间戳供口型驱动 |
| LLM | Qwen2.5-VL / GLM-4 / DeepSeek | 至少一个多模态模型 |
| RAG | LangChain/LlamaIndex + bge-m3 Embedding | 示范景区资料必须入库 |
| 向量库 | Milvus / Chroma / pgvector | 轻量可用 Chroma |
| 数字人 | Live2D / 开源 2D 数字人 SDK | 赛题建议 2D 方案 |
| 部署 | Docker Compose / 单机云服务器 | 初赛单机即可 |

### 6.3 关键设计原则

1. **问答与渲染解耦**：`/chat/ask` 返回结构化数据（文本 + TTS + 表情），前端/数字人引擎各自消费，便于替换组件。
2. **RAG 优先于纯 LLM**：景区事实性问题必须走知识库检索，降低幻觉，保障 90% 准确率。
3. **异步日志**：会话日志异步写入，不阻塞 5 秒响应 SLA。
4. **降级策略**：TTS 失败 → 仅文字；LLM 超时 → 返回 FAQ 模糊匹配结果；ASR 失败 → 引导文本输入。
5. **配置热更新**：数字人形象/音色配置发布后，C 端下次请求自动拉取，无需重启。
